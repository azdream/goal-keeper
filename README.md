# Goal Keeper

목표를 잃지 않고 매일 한 걸음씩 실행하게 돕는 단일 HTML 앱입니다.
설치도 서버도 필요 없고, 데이터는 각자 브라우저(localStorage)에만 저장됩니다.

## 기능

- **목표 → 다음 행동 → 매일 체크인**: 큰 목표를 30~90분 단위 행동으로 쪼개고, 매일 하나씩 체크합니다.
- **연속일(스트릭) / 멈춤 경고**: 3일 이상 손대지 않은 목표를 알려줍니다.
- **빠른 시작 온보딩**: 기본정보 + 설문 → 분류×기간(21칸) 관심 지도 → 추천 목표 자동 생성.
- **말로 설명(선택)**: 음성/텍스트로 생활을 말하면 관심 영역과 목표 후보를 뽑아줍니다. (브라우저 내 키워드 분석)
- **BMI 기반 건강 목표**: 키·몸무게를 넣으면 감량/유지 목표와 기한을 계산해 제안합니다. (참고용 추정, 의학적 진단 아님)
- **Google Tasks 연동**: 목표마다 Google Tasks 목록을 만들고 행동을 할 일로 올립니다. 완료는 양방향 반영.
- **기록 히트맵 · JSON 내보내기/가져오기**

## 로컬에서 실행

`file://` 로 열면 Google 로그인이 동작하지 않습니다. 로컬 서버로 열어주세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 배포 (GitHub Pages)

`index.html` 이 저장소 루트에 있으면 Settings → Pages → Source: `main` / `/` 로 지정하면 됩니다.
공개 주소: `https://<사용자명>.github.io/<저장소명>/`

## Google Tasks 연동 설정

1. console.cloud.google.com 에서 프로젝트 생성
2. **API 및 서비스 → 라이브러리** 에서 `Google Tasks API` 사용 설정
3. **OAuth 동의 화면** 구성 (외부 + 테스트 사용자에 본인 계정 추가)
4. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션** 생성
   - **승인된 JavaScript 원본**에 앱 주소를 등록합니다. 경로는 빼고 스킴+호스트만:
     - GitHub Pages: `https://<사용자명>.github.io`
     - 로컬: `http://localhost:8000`
   - 승인된 리디렉션 URI는 필요 없습니다.
5. 앱의 **기록 탭 → Google Tasks 연동** 카드에 클라이언트 ID를 붙여넣고 `ID 저장` → `Google 연결`

### 알아둘 점

- 접근 토큰은 약 1시간 후 만료되어 다시 연결이 필요할 수 있습니다. 토큰은 저장하지 않습니다.
- 설정 반영에 5분~몇 시간이 걸릴 수 있습니다.
- **클라이언트 보안 비밀(secret)은 이 앱에 필요하지 않습니다.** 저장소·문서·이슈 어디에도 넣지 마세요.
- 앱 자체에는 로그인 기능이 없습니다. 주소를 아는 사람은 누구나 열 수 있으므로, 데이터는 각 브라우저에만 남습니다.

## 개인정보

- 목표, 기록, 키·몸무게 등 입력값은 **브라우저 localStorage** 에만 저장되며 서버로 전송되지 않습니다.
- Google Tasks 연동 시에만 Google API로 할 일이 전송됩니다.
- 주소(origin)가 바뀌면 데이터가 분리됩니다. 옮길 때는 기록 탭의 JSON 내보내기/가져오기를 사용하세요.
